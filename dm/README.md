danmaku.txt中更改弹幕显示
colors.txt中更改颜色，支持RGB格式和16进制颜色码
fonts文件夹中放入字体文件.ttf
***font_config.json中编写按键，可以直接用记事本打开，注意每一段后面都要打逗号，如果是最后一段则不需要***
***注意"K_1"中K是必须的下划线后面则是按键例如"K_j"注意j为小写***

**Windows系统自带的字体路径**
C:/Windows/Fonts/msyh.ttc
可以直接写在json文件中写入,例如{"K_1": "C:/Windows/Fonts/msyh.ttc"}

**MacOS**
路径为/System/Library/Fonts/STHeiti Medium.ttc

**文件运行点击danmu.exe**
